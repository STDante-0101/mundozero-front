# MundoZero Front

Frontend do projeto MundoZero — interface web construída com React, TypeScript e Webpack/Vite.

## Requisitos

- [Node.js](https://nodejs.org/en/download) (versão mínima no `.nvmrc`)
- npm (incluso no Node.js)

## Instalação

```sh
git clone https://github.com/STDante-0101/mundozero-front.git
cd mundozero-front
npm install
```

## Desenvolvimento

```sh
npm start
```

## Build

```sh
# Build de produção
npm run build

# Build de desenvolvimento (com sourcemaps)
npm run build:development
```

## Docker

```sh
docker-compose up -d
```
